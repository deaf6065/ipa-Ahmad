# IPA Ahmad

لوحة ويب عربية لإدارة ملفات IPA وZIP. تتيح رفع النوعين بشكل منفصل، وحفظ بيانات الملفات في SQLite، وفك ملفات ZIP وفحص محتوياتها بأمان. لا يحوّل رفع ZIP إلى IPA.

## التشغيل

يتطلب Node.js إصدار 22.13 أو أحدث.

```sh
npm install
npm start
```

افتح `http://localhost:3000`. تحفظ الملفات وقاعدة البيانات افتراضياً في مجلد `data/` داخل المشروع.
قبل إتاحة الخادم على الإنترنت، ضعه خلف مصادقة مناسبة وقيّد الوصول إلى لوحة الإدارة ومجلد البيانات.

### إعدادات الخادم

| متغير البيئة | الافتراضي | الوصف |
| --- | --- | --- |
| `PORT` | `3000` | منفذ خادم الويب |
| `DATA_DIR` | `./data` | مجلد قاعدة SQLite والملفات المرفوعة |
| `MAX_FILE_SIZE` | `1073741824` | الحد الأعلى للرفع بالبايت (1 غيغابايت) |

## الاستخدام والواجهات

- استخدم زر «رفع ملف IPA» لقبول ملفات `.ipa` فقط، وزر «رفع ملف ZIP» لقبول ملفات `.zip` فقط.
- يظهر تقدم الرفع ورسائله، ثم تُعرض الملفات التي تم حفظها بنجاح مع الاسم والحجم وتاريخ الرفع.
- زر «فك الضغط وفحص المشروع» يفك ZIP إلى `DATA_DIR/extracted/<معرّف الملف>` ويعرض عدد الملفات وحجمها ومجلدات المستوى الأعلى. لا تُنفّذ الملفات المستخرجة.
- يرفض الخادم الملفات التي لا تبدو أرشيف ZIP صالحاً، ويمنع المسارات المطلقة و`..` والروابط الرمزية أثناء الاستخراج. حد الاستخراج ضعفا حد الرفع وبحد أقصى 10,000 مدخل.

واجهات JSON:

- `GET /api/config` — الحد الأعلى لحجم الرفع.
- `GET /api/files` — الملفات المسجلة.
- `POST /api/uploads/ipa` أو `POST /api/uploads/zip` — رفع multipart بحقل `file`.
- `POST /api/files/:id/inspect` — فك وفحص ملف ZIP.

تحد واجهات الرفع والفحص الطلبات المتكررة لكل عنوان عميل، إضافةً إلى حد حجم الملف.
