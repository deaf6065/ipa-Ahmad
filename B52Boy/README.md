# B52 Boy - تطبيق البث المباشر

تطبيق iOS متقدم لبث القنوات الحية بجودة عالية وبدون تأخير.

## المميزات الرئيسية

✅ **بث مباشر عالي الجودة**
- دعم تنسيقات M3U8 و HLS
- بث سلس بدون تقطع

✅ **واجهة سهلة الاستخدام**
- تصميم حديث وجميل
- تنقل سلس بين القنوات
- دعم العربية بالكامل

✅ **تحميل تلقائي للقنوات**
- تحديث فوري عند فتح التطبيق
- خوادم احتياطية للموثوقية العالية

✅ **مشغل فيديو متقدم**
- تحكم كامل بالتشغيل
- إمكانية البحث والتصفية

✅ **إعدادات شاملة**
- معلومات التطبيق
- إدارة الخوادم
- مسح الذاكرة المؤقتة

## المتطلبات

- iOS 14.0 أو أحدث
- Xcode 13.0 أو أحدث
- اتصال إنترنت نشط

## التثبيت والتشغيل

### من خلال Xcode

1. **استنساخ المشروع**:
```bash
git clone https://github.com/deaf6065/ipa-Ahmad.git
cd B52Boy
```

2. **فتح المشروع**:
```bash
open B52Boy.xcodeproj
```

3. **التشغيل**:
- اختر جهاز أو Simulator من القائمة العلوية
- اضغط على زر Play (▶️)
- أو استخدم اختصار لوحة المفاتيح: **Cmd + R**

## الميزات التقنية

### الاتصالات
- **السيرفر الأساسي**: `http://barqbarqbox.shop:80`
- **السيرفر الاحتياطي**: `http://barqbarqbox1.shop:80`
- نظام Fallback تلقائي في حالة فشل الاتصال

### الواجهة
- تم بناؤها باستخدام **SwiftUI**
- دعم كامل للوضع الليلي
- تصميم Responsive

### المشغل
- استخدام **AVFoundation** و **AVPlayer**
- دعم تنسيقات البث الحية
- تحكم كامل بالتشغيل والإيقاف

## استكشاف الأخطاء والمشاكل

### المشكلة: لا تظهر القنوات
**الحل:**
1. تأكد من الاتصال بالإنترنت
2. تحقق من أن الخوادم تعمل بشكل صحيح
3. اضغط على زر "تحديث" في الشاشة الرئيسية

### المشكلة: لا يعمل البث
**الحل:**
1. تحقق من رابط البث (URL)
2. تأكد من دعم الجهاز لتنسيق البث
3. جرب قناة أخرى

### المشكلة: تطبيق بطيء
**الحل:**
1. امسح الذاكرة المؤقتة من الإعدادات
2. أغلق التطبيقات الأخرى
3. أعد تشغيل الجهاز
